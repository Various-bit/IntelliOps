# Knowledge Agent corpus

Reference material for diagnosing centrifugal pumps and telemetry pipelines. The equipment models are examples for interpreting measurements. SKAB evaluation labels and results are excluded.

The date records when the source was checked. Each local note is an original summary. Downloaded originals are stored separately in the ignored `data/corpus/originals/` directory. See [corpus files](../data/corpus/README.md) for the layout.
